<p align="center"><b>More targets, bulk operations and scheduled runs for the BatchPilot plugin.</b></p>

BatchPilot Pro is free while it's in early access.

## What it adds

- Targets for users, comments, terms and media, plus WooCommerce products and orders when WooCommerce is active
- Delete operations for users (with content reassignment), comments, terms and WooCommerce orders, with snapshot-based undo
- Bulk find and replace, including on posts
- Schedules: recurring runs of any target and operation, managed from BatchPilot > Schedules, the REST API or WP-CLI
- Email and webhook notifications for scheduled runs
- A preset for deleting users with no role

## Requirements

- [BatchPilot](https://wordpress.org/plugins/batchpilot/), installed and active
- WordPress 6.3 or later
- PHP 7.4 or later

## Install

1. Download `batchpilot-pro.zip` from the [latest release](https://github.com/jgalea/batchpilot-pro/releases/latest).
2. In WordPress, go to Plugins > Add New > Upload Plugin and upload the zip.
3. Activate it.

New versions show up on the WordPress Updates screen like any other plugin.
